# Examples

These examples show **skill composition**, not just isolated prompts.

1. `01-contract-review.md` — current policy + historical precedent + approval boundary.
2. `02-proposal-reuse.md` — reuse organizational knowledge without copying stale commitments.
3. `03-process-automation.md` — exception discovery → automation architecture → dry run → proof.
4. `04-policy-change-impact.md` — semantic diff + downstream knowledge + reconciliation.
5. `05-data-question.md` — structured files + dictionary + reproducible query.
6. `06-cross-agent-checkpoint.md` — durable work state across harnesses.

When adapting these examples, preserve the **reason for each skill transition**. Do not turn the sequences into mandatory pipelines.
