# Implementation Modes

Choose the simplest reliable mode for each step.

## Deterministic code / rules
Use for stable transformations, validations, calculations, mappings, thresholds, file movement, and exact business rules.

## Database / query
Use for filtering, joining, aggregation, reconciliation, matching, and durable structured state.

## Existing application capability
Prefer existing workflow/system functions when they already implement the needed behavior and controls.

## Agentic reasoning
Use when interpretation, synthesis, fuzzy classification, unstructured evidence, or adaptive planning is genuinely required and errors can be bounded.

## Human gate
Use for authority, accountability, unresolved ambiguity, or risk outside the accepted automation boundary.

## Manual-only / not ready
Use when required capability, policy, data, access, or control does not yet exist. Explicitly identify what must change before automation becomes safe.
